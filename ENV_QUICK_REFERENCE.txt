# Environment Variables Quick Reference

## TL;DR - Add These to GitHub Secrets

| Secret Name | Required? | Purpose |
|------------|-----------|---------|
| `ANDROID_KEYSTORE_BASE64` | ✅ YES | Encode your `.keystore` file in base64 |
| `ANDROID_KEYSTORE_PASSWORD` | ✅ YES | Password for your keystore |
| `ANDROID_KEY_ALIAS` | ✅ YES | Usually `copyclip_key` |
| `ANDROID_KEY_PASSWORD` | ✅ YES | Password for the key inside keystore |
| `PLAY_STORE_JSON_KEY` | ⏸️ OPTIONAL | For automatic Play Store uploads |
| `APPLE_ID` | ⏸️ OPTIONAL | For TestFlight/App Store uploads |
| `APPLE_ID_PASSWORD` | ⏸️ OPTIONAL | App-specific Apple password |
| `APPLE_TEAM_ID` | ⏸️ OPTIONAL | Your Apple Developer Team ID |
| `FASTLANE_USER` | ⏸️ OPTIONAL | Same as APPLE_ID |
| `FASTLANE_PASSWORD` | ⏸️ OPTIONAL | Same as APPLE_ID_PASSWORD |
| `MATCH_GITHUB_TOKEN` | ⏸️ OPTIONAL | GitHub token for iOS certs |
| `SLACK_WEBHOOK_URL` | ⏸️ OPTIONAL | For Slack deployment notifications |

## Step-by-Step Setup

### Step 1: Create Local `.env` File
```bash
# Copy template
cp .env.example .env.local

# Edit values
nano .env.local
# OR use the interactive setup script:
chmod +x scripts/setup_env.sh
./scripts/setup_env.sh
```

### Step 2: Generate Android Keystore
```bash
# Only if you haven't already done this
keytool -genkey -v -keystore ~/copy_clip_release.keystore \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -alias copyclip_key
```

### Step 3: Add GitHub Secrets
**Option A: Interactive Script**
```bash
chmod +x scripts/setup_github_secrets.sh
./scripts/setup_github_secrets.sh
```

**Option B: Manual - GitHub Web UI**
1. Go to your repo: GitHub > Settings > Secrets and variables > Actions
2. Click "New repository secret"
3. Add each secret one by one:
   - Name: `ANDROID_KEYSTORE_BASE64`
   - Value: `(base64-encoded keystore)`
   - Click "Add secret"

**Option C: Manual - GitHub CLI**
```bash
# Encode your keystore
base64 -i ~/copy_circle_release.keystore | pbcopy

# Add to GitHub
gh secret set ANDROID_KEYSTORE_BASE64
# Paste the base64-encoded content when prompted

# Add other secrets
gh secret set ANDROID_KEYSTORE_PASSWORD
gh secret set ANDROID_KEY_ALIAS
gh secret set ANDROID_KEY_PASSWORD
```

### Step 4: Test Locally
```bash
# Build debug APK (uses .env.local)
flutter pub get
flutter run

# Build signed APK (requires signing setup)
./scripts/local_build_signed.sh
```

### Step 5: Commit & Push
```bash
git add .env.example .gitignore .github/
git commit -m "ci: add environment setup files"
git push origin main
```

### Step 6: Trigger CI
- Open a PR or push to `main`
- Watch GitHub Actions run
- Check build status

### Step 7: Create Release (Optional)
```bash
git tag v1.0.0
git push origin v1.0.0
# Release workflow triggers automatically
```

## Environment Variables Explained

### Local Development (`.env.local`)

| Variable | Value | Where Used |
|----------|-------|-----------|
| `FLAVOR` | `dev` | Dart code to identify environment |
| `BUILD_MODE` | `debug` | Dart code to identify build type |
| `ENABLE_ANALYTICS` | `false` | Feature flag for Dev |
| `ANDROID_PACKAGE_NAME` | `com.technopradyumn.copyclip` | Android manifest |
| `IOS_BUNDLE_ID` | `com.technopradyumn.copyclip` | iOS build configuration |

### Signing (Keystore)

| Variable | Example | Where Used |
|----------|---------|-----------|
| `KEYSTORE_PATH` | `$HOME/copy_clip_release.keystore` | Flutter build command |
| `KEYSTORE_PASSWORD` | `your_password` | Passed via `--dart-define` |
| `KEY_ALIAS` | `copyclip_key` | Passed via `--dart-define` |
| `KEY_PASSWORD` | `your_key_password` | Passed via `--dart-define` |

### Production / CI/CD (GitHub Secrets)

| Secret | Example | Source |
|--------|---------|--------|
| `ANDROID_KEYSTORE_BASE64` | `MIIJr...` (very long) | `base64 < keystore` |
| `ANDROID_KEYSTORE_PASSWORD` | `my_secure_password` | Keystore creation |
| `ANDROID_KEY_ALIAS` | `copyclip_key` | Keystore creation |
| `ANDROID_KEY_PASSWORD` | `my_key_password` | Keystore key creation |

## Adding `.env` to Dart Code

### `pubspec.yaml`
```yaml
dependencies:
  flutter_dotenv: ^5.0.0

flutter:
  assets:
    - .env.example
    - .env.local
    - .env.production
```

### `main.dart`
```dart
import 'package:flutter_dotenv/flutter_dotenv.dart';

void main() async {
  // Load environment file
  await dotenv.load(fileName: '.env.local');
  
  runApp(const MyApp());
}

// In your code
String apiUrl = dotenv.env['API_BASE_URL'] ?? 'https://api.example.com';
bool analyticsEnabled = dotenv.env['ENABLE_ANALYTICS'] == 'true';
```

### Usage Anywhere in App
```dart
String apiBaseUrl = dotenv.env['API_BASE_URL']!;
String flavor = dotenv.env['FLAVOR'] ?? 'dev';

if (dotenv.env['ENABLE_ANALYTICS'] == 'true') {
  initializeAnalytics();
}
```

## Common Issues & Fixes

| Issue | Solution |
|-------|----------|
| `.env.local` file not loading | Add to `pubspec.yaml` assets: `- .env.local` |
| Secret not found in workflow | Verify exact name matches (case-sensitive) |
| Build fails with keystore error | Ensure `ANDROID_KEYSTORE_BASE64` is base64-encoded correctly |
| `API_BASE_URL` returns null | Check `.env.local` exists and is readable |
| CI fails but local build works | GitHub Secrets might not be set; run `gh secret list` |
